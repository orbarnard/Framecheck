Framecheck is installed.

Find it in the Start menu, or pin it to your taskbar: press Start, type
"Framecheck", then right-click it and choose "Pin to taskbar".

Getting started
---------------

  1. Open File, or Open Folder, or drag a file onto the window.
  2. Go to the VALIDATE tab and tick a destination (Streaming / CTV, YouTube,
     Meta, and so on).
  3. CONFORM shows exactly what will change before anything happens.
  4. EXPORT writes the new file, then re-reads it from disk and validates it
     again.

Your source files are never modified. Every export is a new file, named
FC_<DESTINATION>-<original name> so you can tell at a glance what it is and
where it is going.

Everything runs on this machine. Nothing is uploaded anywhere.

Custom delivery specs
---------------------

Use Help > Open Custom Specs Folder. Any delivery spec JSON you put there is
loaded alongside the built-in ones, and one with the same "id" as a built-in
replaces it -- copy a built-in from the "specs" folder in the installation
directory to start from. Then use Help > Reload Profiles.

Updates never touch that folder. Do not edit the "specs" folder in the
installation directory: each update replaces it. (If you already did, setup
moved your edited files into the custom folder for you.)
